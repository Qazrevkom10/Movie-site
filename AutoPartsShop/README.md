# TurboParts

Демо-макет интернет-магазина автозапчастей и аксессуаров.

## Что внутри

- главная витрина;
- поиск по товарам;
- подбор по марке, категории и бюджету;
- каталог с демо-товарами;
- корзина;
- форма заявки;
- базовые SEO-файлы `robots.txt` и `sitemap.xml`.

## Как открыть

Откройте файл `AutoPartsShop/index.html` в браузере.

Для публикации нужно заменить `https://example.kz/` в `index.html`, `robots.txt` и `sitemap.xml` на настоящий домен.
